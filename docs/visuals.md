# Visual assets and sources / 视觉资源与来源

[English home](../README.md) · [中文首页](../README.zh-CN.md)

Midnight navy frames the research story, ice-white carries the slides, blue marks navigation and selection, and coral-orange highlights the evidence boundary. The README covers and interactive examples share these roles. Individual research talks can use a palette suited to their own subject.

深海军蓝承载研究故事，冰白呈现投影片，蓝色表示导航与选中状态，珊瑚橙强调证据边界。README 封面与互动示例使用同一套颜色语义。技能生成的具体研究汇报仍应按主题选择适合的配色。

The covers use regular upright book-serif typography in English and Songti in Chinese. The title block has relaxed spacing within the original storyboard composition.

封面英文采用规整的直立书籍衬线体，中文采用宋体；在原有分镜构图内，以舒展的标题间距建立层次。

The covers are conceptual illustrations, not screenshots or scientific results. The preview images are captured directly from the current HTML examples at 1280 × 720. Each README displays one example screenshot linked to its corresponding interactive edition.

封面属于概念示意，不是应用截图或科研结果。预览图直接截自当前 HTML 示例，尺寸为 1280 × 720。每版 README 展示一张实际截图，并链接到对应语言的互动演示。

Both examples use native HTML and CSS for the storyboard and inline JavaScript for navigation, role tabs, and a source dialog. The Chinese edition translates the same three-slide narrative and controls. Neither edition contains experimental findings. No external runtime assets, photographs, third-party logos, or private research materials are used.

两个示例使用原生 HTML 与 CSS 构建分镜，使用内联 JavaScript 实现翻页、论证任务切换与来源弹窗。中文版翻译同一份三页叙事与控件。两版均不包含实验研究结果，也未使用外部运行资源、摄影作品、第三方 Logo 或私人研究材料。
